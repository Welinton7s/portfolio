# 🌐 Portfólio Pessoal — Welinton Araújo

Projeto de portfólio pessoal desenvolvido como atividade prática do curso 
de Desenvolvimento Full Stack Java. O objetivo é apresentar minha trajetória, 
habilidades e projetos como desenvolvedor em formação.

---

## 📋 Sobre o Projeto

Landing page responsiva com as seguintes seções:

- **Hero** — apresentação pessoal com nome, cargo e botão de chamada para ação
- **Sobre mim** — descrição profissional e tecnologias dominadas
- **Consultar CEP** — integração com a API pública ViaCEP
- **Contato** — formulário com nome, e-mail e mensagem

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
- API ViaCEP (https://viacep.com.br)
- Git e GitHub

## 🚀 Como executar

1. Clone o repositório:
```bash
git clone https://github.com/Welinton7s/portfolio.git
```

2. Acesse a pasta do projeto:
```bash
cd portfolio
```

3. Abra o arquivo `index.html` no navegador.

> Não é necessário instalar nenhuma dependência — o projeto roda direto no navegador.
